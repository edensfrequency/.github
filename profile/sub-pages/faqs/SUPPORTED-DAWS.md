## 🖥️ What DAWs and Operating Systems Are Supported?

**Windows only for now.** macOS support is planned but not built yet.

We've actually tested these DAWs and confirmed they work:

- Reason
- FL Studio
- Ableton Live

Any other host that supports the VST3 standard should load our plugins fine, we just haven't personally verified it yet. If you try one that isn't on this list, let us know how it goes (see **[reporting bugs](REPORTING-BUGS.md)**, the same channel works for "this worked in X too").

Don't want to deal with a DAW at all? Every product also runs as a **standalone application** with no host required. See **[what's a DAW](WHATS-A-DAW.md)** if that distinction isn't clear yet, or **[how to install](HOW-DO-I-INSTALL.md)** to get started.
