# 🧪 Development Status

> ### First Public Release Cycle

We're in our first public release cycle, still adding features and polish as real usage turns things up. Every bug found so far has been fixed - see **[🐛 Bugs](BUGS.md)** for the list.

### Where development attention is going

| Product | Status | Focus |
|---|:---:|---|
| [Boom Bap Producer Pads](../products/pads/boom-bap-producer-pads.md) | 🔧 Active | Our one product - new features and polish |
| [Boom Bap Producer Decks](../products/decks/boom-bap-producer-decks.md) | Discontinued | Folded into Pads (the TURNTABLE tab) |
| [Boom Bap Producer Keys](../products/key-sampler/boom-bap-producer-key-sampler.md) | Discontinued | Folded into Pads (the keyboard and SYNTH) |

See also: **[🐛 Bugs](BUGS.md)** for what's been found and fixed, and **[🔄 Releases](RELEASES.md)** for how fixes ship.

### What's coming up

Not scheduled or dated, just the real backlog - what's actually being considered next, not a promise of when.

**Pads:**
- Fixes and features from what testers report, and from making music with it ourselves
- Preset and sample kits made for it: the most likely next venture

Much of the old backlog has shipped in Pads since this page last changed: recording into a pad, a light theme, more languages, stems on the deck, keyboard and screen-reader support. Decks and Key Sampler won't get further work: see **[what moved where](../ONE-PRODUCT.md)**.
